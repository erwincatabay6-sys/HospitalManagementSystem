
Hospital Management System (Java Console Application.)

Project description:
I built this project to explain how software can improve hospital management. This project aims to modernize a traditional hospital management system, With the intent of Implementing it with modern features and practices.
This Console app is the foundation and my growth as an aspiring developer who wish to learn designing architecture, database integration, REST API's, Authentications & Security to deployment and
many more as this project continues to evolve. But I started from zero by developing this Hospital Management System console app, At first this project was made as a hobby but this continues to evolve
out of curiosity before i knew it I was Inspired by the operational challenges that many hospitals face. with this project that im modernizing is to solve and ease the difficulty that hospitals 
go through everyday from Managing patients to processing billing and payments with organized data management & archives etc. Note this console is only the first stage of the project
not the final product. This will become my foundation of my Modern enterprise development.

This Console App Features;

-Patient Management
-Billing System
-Prescription Management
-Medical Information

Project Structure:

>src
>hospitalManagementSystem(Package)
>DuplicatePatientIdException.java
// Custom exception used to prevent duplicate patient IDs while demonstrating custom exception handling.
>Hospital.java
// Core manager of the application. Handles hospital operations, business logic, data management, sorting, console logging, and file persistence.
>InputHelper.java
// Utility class that centralizes input validation to promote clean code, code reusability, and easier maintenance.
>Main.java
// Entry point of the application. Provides the console-based user interface and access to the system's features.
>Patient.java
// Represents a patient entity. Stores patient information, medical records, billing details, and payment receipts while demonstrating Object-Oriented Programming principles.
>Payment.java
// Manages payment transactions and maintains payment history while demonstrating Object-Oriented Programming concepts.
>Prescription.java
// Represents patient prescriptions by managing medicine names, dosages, and usage instructions while demonstrating Object-Oriented Programming principles.

Installation:

Getting Started

Prerequisites
- Java Development Kit (JDK) 17 or later
- A Java IDE (Eclipse, IntelliJ IDEA, or Visual Studio Code)

Installation

1. Clone this repository.
2. Open the project in your preferred Java IDE.
3. Import the project into your IDE if required.
4. Run `Main.java` to start the application.
